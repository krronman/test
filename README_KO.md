# Marble Arena — Render 호스팅용

학교 PC에 Node.js를 설치하지 않고도 게임을 공개 호스팅에 배포할 수 있도록 구성한 프로젝트입니다. Node.js는 호스팅 서버에서 실행됩니다.

## 파일
- `server.js`: 웹페이지와 멀티플레이 상태 서버
- `arena.png`: 경기장 배경
- `sprites.png`: 캐릭터 스프라이트
- `package.json`: 호스팅 플랫폼의 실행 설정

## Render 배포 방법
1. ZIP 압축을 풉니다.
2. GitHub에서 새 저장소(repository)를 만듭니다.
3. 이 폴더 안의 파일 5개를 저장소 최상위(root)에 업로드합니다.
4. Render에 로그인하고 `New +` → `Web Service`를 선택합니다.
5. GitHub 저장소를 연결합니다.
6. 설정은 다음처럼 지정합니다.
   - Runtime: `Node`
   - Build Command: `npm install`
   - Start Command: `npm start`
   - Instance Type: `Free` (테스트용)
7. `Create Web Service`를 눌러 배포가 끝날 때까지 기다립니다.
8. Render가 제공한 `https://...onrender.com` 주소를 열어 게임을 확인한 뒤 그 주소를 친구에게 공유합니다.

## 알아둘 점
- 학교 PC에서 `server.js`를 실행할 필요가 없습니다. 호스팅 서버에서 실행합니다.
- 게임은 공개 인터넷에서 접속할 수 있게 되므로 닉네임에 실명·개인정보를 사용하지 마세요.
- 무료 서비스는 한동안 사용하지 않으면 잠들 수 있으며, 다음 접속 때 시작까지 시간이 걸릴 수 있습니다.
- 이 버전은 같은 공개 인스턴스에 접속한 플레이어들의 위치를 메모리에서 공유합니다. 서버가 재시작되면 현재 플레이어 세션은 사라집니다.
- 이 프로토타입에는 계정/비밀번호, 방 코드, 전투·체력 시스템이 없습니다. 링크를 아는 사람이 접속할 수 있으므로 실험용으로 사용하세요.
